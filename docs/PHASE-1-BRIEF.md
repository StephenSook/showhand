> WHAT SHOWHAND IS: a person records several takes of one in-place move. Showhand runs each take through NVIDIA's stock path (credited as such) and grades it: how well the simulated G1 reproduced what the human did, whether it stayed balanced, and which seconds of the take the demonstrator should re-show. NVIDIA Nemotron 3.5 Lightning on Token Factory fuses the evidence into accept or re-show with second ranges, and that fusion must be measured against each signal alone.
>
> PHASE 1 DELIVERABLES
> 1. Offline take pipeline (scripts run in WSL, Python package showhand/): take video -> GEM-X pose (offline, saved SMPL/SOMA sequence) -> replay into SONIC sim at 50 Hz -> record the G1's joint trajectory, base pose and fall events per sim step -> render the sim run to mp4 (offscreen if the repo supports it, otherwise record the WSLg window as SPIKE-02 did) -> write one take record JSON with every artifact path and timing.
> 2. Physics and tracking metrics per take, deterministic, per second and overall: retargeted human joint angles vs G1 joint angles (error after the retargeter, name the retargeter used), root height and tilt, foot slip, falls, time out of balance. Thresholds go in config/thresholds.yaml, COMMITTED BEFORE THE FIRST GRADED RUN, with a comment that they are frozen; record the commit SHA in every take record.
> 3. Visual judge on Nebius AI Cloud: an NVIDIA Cosmos reasoning model that fits a 48 GB L40S (check the model card on Hugging Face for the exact id, license and GPU requirement; if no Cosmos reasoning model fits or loads, say so and stop that step) run as a Serverless Job over side-by-side frames of the human clip and the G1 render, asked a fixed question per second window (does the robot's pose match the human's?) with structured output; record raw outputs, timings and GPU cost.
> 4. Fusion: nvidia/Nemotron-3_5-Lightning on Token Factory (temperature 0, enable_thinking false, json_schema strict) receives the per-second metrics and the visual verdicts and returns {decision: accept|reshow, reshow_windows: [{start_s, end_s, reason}], evidence_refs}. A deterministic guard rejects any window or reason not grounded in the metrics or verdicts (same idea as Labelhand's agent guard).
